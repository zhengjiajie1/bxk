# 二手交易平台后端

## 验证码功能配置说明

本项目新增了验证码功能，用于用户注册时的安全验证。以下是相关配置和使用说明：

### 依赖要求

- Redis服务：验证码存储使用Redis，请确保已安装并启动Redis服务
- 默认配置：localhost:6379，可在application.yml中修改

### 相关API

- 获取验证码：`GET /captcha/generate` - 返回验证码图片和验证码ID
- 注册接口：`POST /user/sign-in` - 已更新为支持验证码验证

### 使用流程

1. 前端调用验证码生成接口获取验证码图片
2. 用户填写注册信息和验证码
3. 提交注册信息时，同时提交验证码ID和用户输入的验证码
4. 后端验证验证码是否正确，正确则允许注册

### 数据结构

- 验证码生成接口返回：
```json
{
  "status_code": 1,
  "data": {
    "captchaId": "验证码唯一ID",
    "captchaImage": "Base64编码的验证码图片"
  }
}
```

- 注册接口请求：
```json
{
  "userModel": {
    // 用户信息
  },
  "captchaId": "验证码唯一ID",
  "captchaText": "用户输入的验证码"
}
```

### 注意事项

- 验证码有效期为5分钟
- 验证码使用后将立即失效，不可重复使用
- 验证码区分大小写
